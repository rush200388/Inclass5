# Before GitHub submission

Open `src/app/index.tsx` and replace:

- `YOUR NAME`
- `YOUR EMAIL`

Then run:

```bash
npm install
npx expo start
```

For GitHub:

```bash
git init
git add .
git commit -m "Create personalized profile app"
git branch -M main
git remote add origin YOUR_GITHUB_REPOSITORY_URL
git push -u origin main
```
