# Personal Profile App

A redesigned personal profile application built with Expo, React Native, TypeScript, and Expo Router.

## Features

- Custom profile dashboard
- Personal name and email section
- Interactive points counter
- About/skills screen
- Responsive Expo Router navigation
- Clean red, white, and slate visual theme

## Run locally

```bash
npm install
npx expo start
```

Then use Expo Go, an Android emulator, iOS simulator, or press `w` for the web version.

## Personal details

Before submitting, open `src/app/index.tsx` and replace:

```ts
const PROFILE_NAME = "YOUR NAME";
const PROFILE_EMAIL = "YOUR EMAIL";
```

with your own details.
